# Jellyfin Raspberry Pi RTX 4090 architecture

For Jellyfin with a Raspberry Pi and an RTX 4090 PC, run the Jellyfin server on the 4090 PC if GPU transcoding is desired. The Raspberry Pi can be a client, helper, storage/controller node, or SSH target, but it cannot directly use the RTX 4090 just because it is connected by USB or physically nearby.

Clean control path: CyntOX/AI on the 4090 PC controls the Pi over SSH or USB Ethernet gadget if configured. Plain USB alone does not provide shell control.
