# Mythos prompt design provenance

The v2 candidate is staged at `prompts/mythos-system.md` for controlled evaluation. The adopted runtime remains the verbatim v1 prompt at `prompts/archive/mythos-system-v1.md` unless a process explicitly sets `CYNTOX_MYTHOS_V2_CANDIDATE=1`; candidate evaluation itself always binds the explicit v2 path and hash, independent of that runtime selector. V2 is not adopted until the prompt A/B safety, regression, length, deterministic-score, and all-case blind material-defect gates pass. Keeping v1 as the default makes rollback immediate while the independent blind review remains pending. `config/Modelfile.cyntox` intentionally contains only a minimal identity and safety fallback; it is not the full behavior specification.

V2 was informed by selected general reliability ideas in [`universal/balanced.md`](https://github.com/KinetiNode/claude-fable-5-system-prompt-clean/blob/c2624b5fa0f3e5d03ded01a8d6f66e6f661f016b/universal/balanced.md) from commit `c2624b5fa0f3e5d03ded01a8d6f66e6f661f016b` of `KinetiNode/claude-fable-5-system-prompt-clean`. The upstream repository declares the material under the [MIT License](https://github.com/KinetiNode/claude-fable-5-system-prompt-clean/blob/c2624b5fa0f3e5d03ded01a8d6f66e6f661f016b/LICENSE) (copyright 2026 KinetiNode).

The CyntOX text is a concise paraphrase, not a reproduction. It retains CyntOX-specific local privacy, authorization, device-change, defensive-testing, evidence, and prompt-injection boundaries. Upstream provenance beyond the repository's own declaration has not been independently established, so the source is treated as third-party inspiration rather than authoritative model documentation.
